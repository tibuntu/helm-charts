# tibuntu Helm charts

This branch hosts the Helm repository index for the charts in
[tibuntu/helm-charts](https://github.com/tibuntu/helm-charts).

```bash
helm repo add tibuntu https://tibuntu.github.io/helm-charts
helm repo update
helm search repo tibuntu
```

Chart sources, documentation and issues live in the
[main repository](https://github.com/tibuntu/helm-charts).
